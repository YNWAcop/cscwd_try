# 数据边界与输入契约

请自行取得 CH-SIMS、CH-SIMS v2、UniC 的合法访问权限。仓库不再分发其媒体、特征、单模态标注或逐样本预测，也不包含将受限数据下载到公开仓库的脚本。

可移植入口使用一个已经完成历史预处理的 NPZ 外折，`allow_pickle=False`：

| 键 | 形状/类型 | 含义 |
|---|---|---|
| x | float32 [N,24] 或 [N,96] | 按 Text、Audio、Vision 拼接的投影特征 |
| y | float32 [N] | 整体情感评分，原协议尺度 [-1,1] |
| u | float32 [N,3] | 独立人工单模态评分，顺序 T/A/V |
| id | 字符串 [N] | 唯一样本标识 |
| source | 字符串 [N] | 来源组，三个划分必须互斥 |
| conflict | bool [N] | 原研究定义的冲突标记，不允许用模型预测替代 |
| fit/tune/holdout | bool [N] | 互斥且完备的三个非空划分 |

历史特征流程：模态时序均值/标准差池化，FIT均值/标准差归一化；每模态 PCA（8或32维，randomized、random_state=123）；投影后再次用FIT统计归一化并截断到[-8,8]。精确数值实现见 `projector`。PCA、归一化不得使用 TUNE 或 holdout。

本次发布没有提供三个原始数据格式到此 NPZ 的通用转换器，也没有公开历史逐样本划分。因此能复核公开汇总和运行相同算法，不等于不需授权数据就能重现所有历史数字。要精确重现，需持有原数据、对应去重队列、划分与历史预处理缓存；90组记录保存了原检查点和预测文件的哈希供持有者核对。
