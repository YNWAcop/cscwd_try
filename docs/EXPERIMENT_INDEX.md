# 实验索引与筛选依据

| 阶段 | 内容 | 归档定位 |
|---|---|---|
| 150 | 来源交叉拟合、正向误差增加惩罚 | 失败/边界参照：没有超过简单残差，保留协议和原脚本 |
| **151** | **连续模态条件差异监督** | **主候选：完整六设置结果、90组已核验记录、可移植数值核心** |
| 152 | 旧冲突重加权扩展到五种子 | 动机证据：组内收益可能伴随其他组及整体损失 |
| 153 | 双重中心化 | 未优于主候选的复杂化探索，不作为额外创新 |
| 154 | 主候选的全局、来源、评分与精确单元打乱 | 机制诊断：保留有利和不利结果，不能解释为因果证据 |
| 155 | 已有预测的配对消融审计 | 结果表已归档；现代骨干工作仅到接口审计，未做性能宣称 |

Stage151 包含28个分支：task-only、普通多任务、冲突加权、二元冲突监督、仅条件项、主候选、低/高系数、打乱普通辅助，以及19次精确单元打乱。

90组 = 2维度 × 3队列 × 3外折 × 5种子；每组28分支共2520个轻量网络拟合。它们不是2520次独立数据验证。

`archive/original_scripts` 是历史实验脚本原件，其原有本地依赖链未打包，不能把该目录当成独立安装包。`src` 和 `scripts/train.py` 才是新的可移植入口。新入口不接入或重启本机关机授权。

当前尚缺：现代骨干公平对照、可靠的独立增量证据、确认资格明确的新数据/协议，以及据证据重写论文。没有据此估计80%录用率。
