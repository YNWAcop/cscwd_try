# 2026-11-11：冲突监督算法探索、证据整改与当前判断

## 一、结论先行

本轮实际完成了三轮新算法探索、原重加权实验的五种子扩展，以及新候选自身的完整四种标签打乱对照。当前保留的候选是 **来源—评分条件下的连续模态差异监督（Stage151）**。它在三个队列、两种统一特征维度的六个设置中，相对普通单模态辅助多任务学习的平均 MAE 均下降；但六个差值的 95% 区间全部跨零。它比“仅做主任务”在五个设置中有正向点估计，不是六个全部占优。

这满足“有改善就保留候选”的探索标准，尚不满足“已证明稳定新增贡献”的论文主张。另两轮方案未获得足够增量证据，保留失败记录，暂不作为论文核心模块。无法据此核定 80% 录用概率，也没有把仍未补齐的审稿风险标成完成。

用户的核心问题可以保留：**模态情感不一致包含什么有用信息，怎样利用这些信息而不掩盖其他样本上的代价？** 新方法不是因为采用了更复杂的网络才有价值，而应证明：在相同容量、相同训练预算和相同标注资源下，条件化的连续差异监督确实比普通辅助监督和二元冲突监督更有用。

## 二、如何吸收附件，而不是照单全收

附件关于明确主张、条件打乱诊断、多种子、联合报告收益代价以及公式代码一致性的意见是有效的，已经落实到下述工作。两处需要修正：

1. 相同来源和相同评分内打乱，只保留这些单元的标签多重集合；它并不会自动消除特征与冲突的关联。真实标签优于打乱标签可以支持“样本—标签对应信息有用”的受控算法对照，不能自动解释成冲突的因果效应。
2. 附件的四种收益情形不是互斥完备的四象限：其“理想情况”和“普遍收益”都在双正象限，遗漏了“非冲突改善、冲突退化”。本轮图明确展示四个符号象限；是否冲突特异还需另看 A，不能仅靠象限命名。

方法较早不是拒稿的充分理由。重加权、中心化和辅助任务本来就是成熟工具；需要判断新增的条件监督设计、经验发现和适用边界是否有独立价值。不能只换名字，也不应只因有相关工作就放弃。

## 四、候选方法到底新增了什么

每个样本有整体评分 y 和真实单模态情感标注 u=(u_T,u_A,u_V)。不同于把它压成一个“冲突/不冲突”位，候选保留连续方向和幅度。三个模态编码器产生各自表示，融合分支预测整体情感，三个辅助头预测单模态情感。

对训练中来源和整体评分都相同的单元 s，定义辅助误差 E_im=û_im−u_im。条件项是：

\[
\mathcal L_{cond}=\frac{1}{3|I|}\sum_{i\in I}\sum_m
\left|E_{im}-\frac{1}{|s(i)|}\sum_{j\in s(i)} E_{jm}\right|,
\quad I=\{i:|s(i)|\ge2\}.
\]

总目标固定为 L_task+0.25 L_uni+0.25 L_cond。单例单元不计算条件项，仍参与主任务和普通辅助监督。推理只输入特征，不使用真实 y、单模态标注、冲突标记或来源编号。

例如同一段视频内两个片段的整体标签都接近中性，但一个是“文字偏正、声音偏负”，另一个反过来。二元冲突位将两者混在一起；普通多任务会学习单模态分数，但不专门约束相同来源与相同整体标签下的相对差异。本候选增加的正是这个约束。

这个例子是机制说明，不是伪造的实验案例。中心化是标准操作；数学操作本身不是新发明。可能成立的新增贡献是这种监督定位及其可验证的收益边界。尚不能声称消除全部混杂、强制梯度正交、没有负迁移或确保测试非冲突组不受损。

## 五、候选的真实结果

所有 MAE 均越低越好；“降幅”定义为对照 MAE 减候选 MAE，正值表示改善。每模态 PCA 8/32 维对应总输入 24/96 维，投影和归一化仅在各外折 FIT 上拟合。三个来源互斥外折，五个初始化种子：17、43、89、131、197。每个训练分支 100 次 full-batch AdamW 更新、相同初始化与预算，各分支只按自己的普通 TUNE MAE 选择检查点。

原重加权审计使用普通模型所选的共同 epoch；它与这轮每分支独立选 epoch 的规则不同，不能混称同一实验。跨算法绝对 MAE 只能在协议相同的表内直接比较。不能将本轮 MAE 与官方划分的文献数字直接排名。

## 六、附件最关键的条件打乱问题

既有 Stage131 已在统一 32 维读出接口上完成全局、来源、评分、精确单元四种打乱对照，覆盖 CH-SIMS v1/v2、UniC、CREMA-D。此次核验其 135 份封存记录的哈希均一致；2565 个历史拟合没有重新算作本轮新增。不同数据的标注含义仍有差异，尤其 CREMA-D 不能无条件等同于自然单模态情感冲突。

这些旧对照不能代替对新 Stage151 的全部新对照。因此继续执行了 Stage154，为 Stage151 补齐全局/来源/评分分层打乱，每种 19 次，三模态标签始终作为向量联合置换；精确单元打乱复用 Stage151 原结果。下表是各打乱模型平均 MAE 减真实标签模型 MAE，完整区间在结果 JSON 和四面板图中。Stage153 不再作为主候选，其额外三种打乱没有继续扩展。也不能把旧 3 种子×99 次打乱与新 5 种子×19 次打乱拼称 5×99。

## 七、原方法补到五种子后，主张应怎样改

下表是真实冲突重加权相对均匀训练的全群体结果，接口 native/common 的定义与原实验相同。

| 原重加权设置 | 冲突组降幅 | 非冲突组降幅 | 整体降幅 [95% CI] |
|---|---:|---:|---|
| native_v1 | +0.006042 | -0.004571 | -0.002424 [-0.004709, -0.000582] |
| native_v2 | +0.002060 | -0.004612 | -0.004046 [-0.006138, -0.002112] |
| native_UniC | +0.001625 | -0.008535 | -0.005299 [-0.045171, +0.043018] |
| common_v1 | +0.000786 | -0.004255 | -0.003235 [-0.005108, -0.001187] |
| common_v2 | +0.002904 | -0.004803 | -0.004150 [-0.006494, -0.001907] |
| common_UniC | +0.007618 | +0.009894 | +0.009169 [+0.003051, +0.016505] |

原生 CH-SIMS v1 的冲突组确实改善，但非冲突及整体退化；这一现象在五种子下仍存在。应保留“收益可能转移成其他样本的成本”的问题动机。UniC 与接口变化说明效应依赖设置，但当前实验不能因果分解究竟是数据分布、特征信息、编码器、压缩损失或样本量中的哪一个因素造成。

新 Stage151 在两种统一维度上补了因素对照，减少了“只是维度不同”的解释空间，但没有隔离所有上游特征差异。尤其 UniC 的 32 维绝对 MAE 明显差于 8 维，不能为了统一维度把信息量、容量或过拟合问题视为已解决，也不能事后在每个数据集挑最好的维度作统一主结果。

## 八、实现可信度与新的盲区

1. 检查了 306 个新训练记录/检查点组合的哈希；重放 Stage151/153/152 的 216 个模型批次，以及 Stage150 的 45 组参考—残差组合。所检查的新预测最大重放误差为 0。
2. 原 KL 权重求解器用独立 SciPy 约束求解作了 12 个数值对照；约束可行，最大目标差约 3.17×10^-13。此项不等于非凸神经训练全局收敛保证。
3. 人工模态标注到冲突位的定义逐样本核对一致。新控制器均验证保存/退出握手；旧关机授权没有重启或延长。
4. 找到不能把官方 CH-SIMS test 当“新独立来源验证”的原因：数据审计显示训练与测试有 59 个来源视频重叠；早期 run_pilot.py 已经评价过 test。当前来源划分审计不是因此无效，但官方 test 不能再宣传为未曝光、来源独立的最终确认集。
5. 跨种子与来源 bootstrap 仍以已经训练好的预测为条件，不能覆盖训练来源重新抽样、所有超参数搜索和跨数据集分布转移的不确定性。
6. Stage154 新增 90 个批次、5130 个模型均重放通过，最大预测误差为 0，输入和样本顺序与父实验一致。汇总 CSV 时出现过重复 cohort 字段错误；完整评价 JSON 已成功保存，随后只恢复 CSV 导出，没有重训、重算指标或删去失败记录。

按优先级，而不是继续在同一外折尝试大量名字不同的模块：

1. **现代强基线和容量核查，取得可用代码后预计 2–4 天。** MISR 官方地址当前返回 404，先寻找作者提供的新地址或可核验原版镜像；若最终按论文逐式实现，必须注明自行复现及无法确认的配置，不能冒称作者代码。取得实现后锁定版本、原配置、输入接口及是否使用额外标注；分别标注“官方设置复现”和“本来源划分的协议适配”。先跑稳定 smoke，再在同一数据、同一来源划分与明确的验证搜索预算上完成对比。普通 MTL、仅主任务、二元冲突及参数量/计算量必须同时在表。不能把一个简化损失叫完整 MISR。完成判据是配置、权重、预测与 C/N/A/overall 都可回放，且失败不删除。
2. **候选机制的集中判定，预计 0.5–1 天。** 四种打乱已经补齐，不再重复训练。将零条件项、无普通辅助项、低/高系数的已有消融与这次完整对照合并，核算有效非单例覆盖、群体代价和标签置换强度。固定主系数，不在外折选新阈值。若结果只支持“普通辅助监督有用”，就不宣称中心化条件项带来可靠独立创新；若仍有可检验的差异，冻结方案进入下一步。此项的完成不是把不确定结果修饰成显著结果。
3. **独立确认资格审计，预计 0.5–1 天；数据到位后验证 2–3 天。** 先确认是否有未参与历次调参、与训练来源不重叠且具有整体/单模态标注的数据。不能用官方 CH-SIMS test 冒充。若没有，明确保留探索性定位；重新嵌套验证可以改善内部评价，但不能把已经曝光的数据“洗成”外部独立确认。保留现有小数据策略，不默认下载用户拒绝的巨大 EmotionTalk 数据。
4. **有证据再选择论文主线，预计 2 天。** 若候选在公平强对照及合格确认中有一致、实际可解释的增量，写“条件差异监督方法+收益代价审计”。不要求每格都显著，但核心新增机制必须有直接证据，代价必须透明。若收益主要来自普通辅助标注，保留方法负结果，写“冲突标签何时有训练价值”的经验审计论文；不要虚构强算法贡献。
5. **重写与外审，预计 2–3 天。** Introduction 区分问题新颖与方法贡献；Method 放 Algorithm 1、目标与训练/推理界线；Results 放主对照与收益代价；Discussion 放可交换性、来源少和探索复用边界。精简重复实验，按 6 页预算取舍。邀请真实外部读者分别检验创新、实现及统计证据；不能由同一过程自评代替独立审稿。
